# Contenido de @banderin.app

Imágenes y videos públicos de las publicaciones de Instagram de Banderín.
Metricool los toma desde acá para programar cada publicación.

- `tanda-01/`: las primeras 9 publicaciones (4 reels, 3 carruseles y 2 posts).
- `anuncios/`: piezas de la publicidad paga.
- `tanda-NN/`: una carpeta por semana.
